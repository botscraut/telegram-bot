# 🤖 TG Accounts Shop Bot

Полноценный Telegram-бот для продажи Telegram-аккаунтов с оплатой через CryptoBot (USDT) и Telegram Stars.

## 📦 Возможности

- 🛒 **Магазин аккаунтов** — продажа по странам (🇷🇺🇰🇿🇺🇿🇺🇦🇧🇾🇰🇬)
- 💰 **Двойная оплата** — CryptoBot (USDT) и Telegram Stars
- 👤 **Профиль** — баланс $/⭐, история покупок
- 🔗 **Реферальная программа** — бонусы за приглашённых
- 🎧 **Поддержка** — кнопка перехода на @wanstrelovv
- ⚙️ **Админ-панель** — добавление аккаунтов, помощники, статистика
- 📱 **Автовыдача** — номер и код после оплаты

## 🚀 Быстрый старт

### 1. Создай бота в Telegram

Напиши [@BotFather](https://t.me/BotFather):
```
/newbot
```
Получи токен вида `123456789:ABCdef...`

### 2. Получи токен CryptoBot

1. Напиши [@CryptoBot](https://t.me/CryptoBot)
2. Перейди в `Crypto Pay` → `Create App`
3. Скопируй API Token

### 3. Узнай свой Telegram ID

Напиши [@userinfobot](https://t.me/userinfobot) — получи числовой ID.

### 4. Настрой .env

Скопируй `.env.example` в `.env` и заполни:
```
BOT_TOKEN=123456789:ABCdef...
CRYPTO_BOT_TOKEN=your_cryptobot_token
ADMIN_ID=123456789
```

### 5. Установи зависимости

```bash
pip install -r requirements.txt
```

### 6. Запусти бота

```bash
python bot.py
```

## ⚙️ Админ-панель

Доступна только владельцу (`ADMIN_ID`) и помощникам.

Команды админки:
- 📦 Добавить аккаунт (через FSM — 5 шагов)
- 📋 Список аккаунтов (с кнопкой удаления)
- 👥 Помощники (добавление/удаление)
- 📊 Статистика (продажи, выручка)

## 💳 Оплата

### CryptoBot (USDT)
- Создаётся инвойс через API
- Пользователь оплачивает по ссылке
- Жмёт «Проверить оплату» — бот проверяет статус
- Баланс пополняется автоматически

### Telegram Stars
- Через нативный `send_invoice` с `currency="XTR"`
- Оплата прямо в Telegram
- Баланс пополняется мгновенно

## 🛠️ Доработка

### Добавление помощника по username
В текущей версии помощник добавляется по `user_id`. Для добавления по `@username` нужно:
1. Попросить пользователя написать боту
2. Использовать `callback.from_user.id`

### Webhook (для сервера)
Замени `dp.start_polling(bot)` на:
```python
await dp.start_polling(bot)
# или для webhook:
# await bot.set_webhook("https://yourdomain.com/webhook")
```
